# Next RecipeWeaver release work

RecipeWeaver 3.7 is the latest installable development hotfix. The retained JAR is `releases/RecipeWeaver-3.7.jar`, SHA-256 `3BB76E0EC30CEF39D16AA29B272394978EED130054B7DF14C05DDA10F00B72C8`. All 89 versioned JARs remain in `releases`; all 88 prior JARs still match their pre-audit hashes. Version 3.7 fixes advanced-table native recipe restriction bypasses, missing overflow containers, anvil prompt control leakage, and book prompt submit/cleanup races. It remains an intermediate build below the planned 75-change gate. The [3.7 ledger](releases/3.7-CHANGE-LEDGER.md) and [audit report](audit/CODE-AUDIT-2026-10-11.txt) record this work; the prior 0.2.83 [81-change ledger](releases/0.2.83-CHANGE-LEDGER.md) remains historical evidence for that release.

The 3.7 core suite ran 602 tests across 63 suites: 580 passed, 22 skipped, and none failed. Development, candidate release-mode, and retained-JAR six-server matrices passed on Paper, Purpur, and Spigot at 1.20.6 and 26.2, with installed artifact hashes and the new native crafting regression verified on all 18 final runs. Focused tests cover native fallback restrictions and overflow capacity, anvil ownership/cleanup including shutdown, and book prompt cancellation races. Package checks verified embedded version and author, Java 21 bytecode, seven bundled JDBC driver entrypoints, and exclusion of smoke classes, invalid class names, duplicate ZIP entries, and stale signature metadata. A real player must still retry the corrected Create and Save flow and gameplay transactions; the automated matrices do not click the GUI. Unrestricted raw Minecraft SNBT mutation remains unavailable through the cross-version public Bukkit API.

The next full planned release still requires at least 75 new, distinct, substantive production features or bug fixes after 3.7, each tied to its own executed focused test or live assertion. Tests, smoke markers, fixtures, documentation, type aliases, schema increments, and packaging do not count. Keep every older versioned JAR. The user explicitly skipped installing ItemsAdder, Oraxen, and MMOItems; their live integrations remain pending. MySQL and PostgreSQL application-layer snapshot, restore, live write, read, and delete tests passed on local servers before the version-only 3.5 rebuild; this audit did not rerun them. MariaDB, SQL Server, and Oracle live checks remain pending.
