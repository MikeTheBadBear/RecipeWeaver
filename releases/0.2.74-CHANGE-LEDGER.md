# RecipeWeaver 0.2.74 change ledger

This ledger counts 35 distinct source changes added after 0.2.73. A row counts one behavior or one editable Minecraft data component, including its validation and persistence; helper methods, test markers, schema increments, and packaging changes are not additional counts. The prior 0.2.70–0.2.73 JARs remain intermediate builds and are not retroactively credited with 35 changes.

`ItemComponentSmoke` invokes the production item editor helpers on each real smoke server, checks each changed component, saves the items, then checks reload, backup restore, and full restart recovery. `RW_ITEM_COMPONENT_PASS` and `RW_ITEM_COMPONENT_PRIOR_SAVED=true` are the common server markers. The row evidence identifies the individual assertion. The four component tests skipped by MockBukkit use APIs its mock does not implement; the real server probe covers those paths.
