# RecipeWeaver 0.2.75 change ledger

This ledger accounts for 40 distinct source behaviors added after 0.2.74. Rows 1 through 35 alone meet the required 35-change minimum. Rows 36 through 40 are additional fixes. Validation, persistence support, smoke markers, fixture changes, and packaging are not counted as separate features.

Each numbered row identifies an implementation and an individual assertion. The final development and candidate release-mode smoke matrices passed on Paper, Purpur, and Spigot at 1.20.6 and 26.2. The item editor probes call production edit helpers and check save, reload, backup restore, and restart persistence; actual player clicks remain unverified.

The core suite ran 213 tests: 206 passed, 7 skipped, and none failed. Three skipped tests require remote SQL credentials; four MockBukkit component tests use APIs its mock does not implement. The matching component and item paths were checked on the six real server implementations.

The lit campfire pulse is server behavior, but physical furnace, blast furnace, smoker, and crafter pulses and real player clicks remain unverified. Optional plugin installations, remote SQL preference, additional remote database round trips, every intermediate Minecraft version, and remaining BUILD_PLAN.md milestones are also unverified or unfinished. The 1.20.6 API does not expose CrafterCraftEvent, so rows 19 and 20 apply to the three 26.2 servers.
