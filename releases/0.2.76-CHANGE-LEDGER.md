# RecipeWeaver 0.2.76 change ledger

This ledger records 39 distinct production behaviors added or fixed after 0.2.75. Each row has an individual assertion. Physical probes, test markers, test fixtures, schema increments, documentation, and packaging are verification work and are not counted as features. Development, candidate release-mode, and retained-release six-server matrices passed on Paper, Purpur, and Spigot at 1.20.6 and 26.2. The core suite ran 235 tests: 221 passed, 14 skipped, none failed.
