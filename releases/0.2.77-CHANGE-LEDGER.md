# RecipeWeaver 0.2.77 change ledger

This ledger records 46 distinct production behaviors added or fixed after 0.2.76. Each row identifies a separate assertion in a focused test or server smoke probe. Test markers, schema changes, fixtures, documentation, and packaging are not counted as features. The core suite ran 257 tests: 242 passed, 15 skipped, none failed. Development, candidate release-mode, and retained-release six-server matrices passed on Paper, Purpur, and Spigot at 1.20.6 and 26.2.
