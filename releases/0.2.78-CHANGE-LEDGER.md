# RecipeWeaver 0.2.78 change ledger

This ledger records 51 distinct production behaviors implemented after 0.2.77. Each row names a focused test assertion or a server smoke assertion. The count excludes fixtures, markers, documentation, schema increments, and packaging. The core suite ran 288 tests: 270 passed, 18 skipped, none failed. Development, candidate release-mode, and retained-release six-server matrices passed on Paper, Purpur, and Spigot at 1.20.6 and 26.2.
