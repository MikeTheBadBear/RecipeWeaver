## Completed release verification

The core suite recorded 394 passed, 20 skipped, and 0 failed. The development and candidate release-mode six-server matrices passed on Paper, Purpur, and Spigot at 1.20.6 and 26.2. The retained-JAR matrix also passed all six endpoints: Paper and Purpur 1.20.6 passed initially; Spigot 1.20.6 passed on rerun; and Paper, Purpur, and Spigot 26.2 passed afterward. The first Spigot 1.20.6 retained run had rejected `RW_ITEM_COMPONENT_PRIOR_SAVED=true` because its saved map ID had no Bukkit map view at startup. The map file appeared by that run's shutdown, and the unchanged retained JAR passed the full gate on rerun. This was a smoke world-persistence fixture timing limit; the precise cause of the initial missing map file was not established.

The retained `RecipeWeaver-0.2.81.jar` is 29,256,593 bytes and has SHA-256 `93AA087CDB560B9D3DC8BD002652F86D348DB89D04A683EEEAA358A0C5B8AA97`. Package inspection confirmed embedded version `0.2.81`, author `TM Game Studio`, Java 21 class major 65, seven bundled JDBC driver entrypoints, no smoke classes, no exact duplicate entries, no invalid class filenames, and no stale signature metadata. The case-distinct `META-INF/license.txt` and `META-INF/LICENSE.txt` entries remain. All 83 versioned JARs were retained at this gate.
