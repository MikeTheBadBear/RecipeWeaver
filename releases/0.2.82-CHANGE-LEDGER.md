## Release verification

Core: 491 tests across 57 suites: 471 passed, 20 skipped, 0 failed. All 51 named focused test methods in the rows above appear in the executed JUnit XML; row 38 uses its own physical crafter assertion. The full development, candidate release-mode, and retained-JAR matrices passed on Paper, Purpur, and Spigot at both 1.20.6 and 26.2. The 1.20.6 physical crafter probe warmed the vanilla stick recipe cache, disabled that recipe, and confirmed a second redstone pulse left both inputs and output unchanged before restoring the recipe. Cooking blocks, redstone crafters, and water cauldrons were exercised on physical servers.

`verifyBuildJar`, `releaseJar`, and `verifyReleaseJar` passed. The retained `RecipeWeaver-0.2.82.jar` is 29,272,726 bytes, SHA-256 `EBAC63E6E4E3A734ED3C83B384260E01D510FD6D13479D50AA034BFC9CB848FC`. Its `plugin.yml` identifies version `0.2.82` and author `TM Game Studio`; the main class uses Java 21 bytecode. The package includes seven JDBC driver entrypoints and excludes smoke classes, invalid class filenames, stale signature metadata, and exact duplicate ZIP entries. All 84 versioned production JARs remain in `releases`; the 83 older JAR hashes matched the pre-release baseline exactly, including 0.2.81 SHA-256 `93AA087CDB560B9D3DC8BD002652F86D348DB89D04A683EEEAA358A0C5B8AA97`.

Real player-client menu clicks, cauldron use, and result taking were not exercised. The supported item editor edits typed persistent data, nested compound paths, and exposed item components; arbitrary raw Minecraft SNBT mutation remains unavailable through the cross-version public Bukkit API. Optional plugin JARs and remote database credentials were unavailable for this scoped release.
