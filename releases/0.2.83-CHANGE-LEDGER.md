## Release verification

The final full core run completed with 590 tests across 61 suites: 568 passed, 22 skipped, 0 failed. All 79 individually named focused methods in the rows above appear as passing cases in the executed JUnit XML; rows 44 and 45 use their own physical assertions. Those two head-sound unit methods remain skipped because MockBukkit does not implement the required SkullMeta methods. The map-location methods now pass with RecipeWeaver-owned typed PDC labels because the inspected native MapMeta location-name setters do not round-trip on the tested versions. The distinct map and head assertions, compound-array editor marker, advanced brewing assertion, and overall smoke pass appeared in all six retained server logs.

Development, candidate release-mode, and retained-JAR six-server matrices passed on Paper, Purpur, and Spigot at both 1.20.6 and 26.2. `verifyBuildJar`, `releaseJar`, and `verifyReleaseJar` passed. The retained [RecipeWeaver-0.2.83.jar](RecipeWeaver-0.2.83.jar) is 29,297,146 bytes, SHA-256 `C44168717C1F7F3BC82453C85B27908FAAFED35613FD4155626DEAE283D6C081`. Its `plugin.yml` identifies version `0.2.83` and author `TM Game Studio`; the main class uses Java 21 bytecode. The package includes seven JDBC driver entrypoints and excludes smoke classes, invalid class filenames, stale signature metadata, and exact duplicate ZIP entries. All 85 versioned production JARs remain in `releases`; all 84 older JAR hashes matched the pre-release baseline exactly, including 0.2.82 SHA-256 `EBAC63E6E4E3A734ED3C83B384260E01D510FD6D13479D50AA034BFC9CB848FC`.

Real player-client menu interactions have NOT been verified; no authenticated/controlled player client was available. Optional plugin JARs and remote database credentials were unavailable and outside this scoped release. Unrestricted raw Minecraft SNBT mutation remains unavailable through the cross-version public Bukkit API.
