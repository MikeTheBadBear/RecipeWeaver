# RecipeWeaver 3.6 release record

Version 3.6 is an intermediate hotfix after 3.5. It does not satisfy the planned 75-change production-release gate.

1. The workbench crafting editor now shows a blue 3x3 ingredient grid, a green result slot, numbered guidance, a dynamic Save state, and clearer hover instructions. Ingredient and result clicks refresh the open menu while preserving the cursor-held item. Source: `StudioMenus.java`. The six-server matrices verify plugin loading and automated recipe paths; real player menu clicks remain unverified.
2. `TextPrompt` no longer casts a custom top inventory to `AnvilInventory`. It opens a native anvil where supported, tracks prompt ownership, reads rename text safely, and supplies a visible result paper. A user-supplied Paper 26.2 log established the 3.5 failure. `TextPromptTest` passed both the default-ID path and a custom top-inventory renamed-result path. The corrected flow still needs a real player retest.

The complete core suite ran 592 tests across 62 suites: 570 passed, 22 skipped, 0 failed. Development, candidate release-mode, and retained-JAR smoke matrices passed on Paper, Purpur, and Spigot at 1.20.6 and 26.2. Package verification checked the embedded version, author, Java 21 bytecode, seven JDBC entrypoints, and exclusion of smoke classes and invalid or stale metadata.

Retained artifact: `RecipeWeaver-3.6.jar`, 29,302,080 bytes, SHA-256 `8FD6E13D33E3D5CAD2733BB32ECA71164889B0931BF244EB89BA2F484B0BBCA5`. All 88 older and current versioned JARs remain in `releases`.
