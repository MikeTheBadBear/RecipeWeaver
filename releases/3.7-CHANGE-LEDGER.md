# RecipeWeaver 3.7 release record

Version 3.7 is an intermediate code-audit hotfix after 3.6. It does not satisfy the planned 75-change production-release gate or complete the numbered build-plan milestones.

1. The advanced table's native crafting fallback now enforces disabled native keys and saved RecipeWeaver recipe guards, including exact inputs/results, enabled/lockdown state, and player/world conditions. The world-only Bukkit crafting API does not invoke the normal player event guard. `NativeGridCraftingTest` covers allowed and denied conditions, missing saved recipes, disabled keys, forged outputs, and changed inputs; `NativeGridFallbackSmoke` checks permission denial and acceptance through the production table matcher on real servers.
2. The same fallback now preserves native overflow returns as well as the resulting matrix. Stacked honey bottles return their glass bottle, and output plus returns must fit before committing a craft. Focused tests verify item snapshots and full/partial inventory capacity; the live smoke probe checks real native honey-bottle output and return behavior.
3. Anvil text prompts retain ownership through deferred acceptance, cancel repeated clicks, and clear synthetic paper controls on acceptance, close, replacement, quit, and shutdown. Focused tests cover duplicate submission, replacement/close cleanup, acceptance followed by close, and plugin shutdown cleanup.
4. Book prompts retain protection until deferred cleanup, reject duplicate submissions, and prevent a cancelled session from invoking its pending save callback. Focused tests reproduce the temporary-book movement window and explicit cancellation race.

The complete core suite ran 602 tests across 63 suites: 580 passed, 22 skipped, and none failed. Ten focused regression tests were added. The skipped tests comprise 17 unsupported MockBukkit API cases and five unconfigured opt-in external SQL cases. Development, candidate release-mode, and retained-release six-server matrices passed on Paper, Purpur, and Spigot at 1.20.6 and 26.2. All 18 final runs verified the installed JAR hash and the new native crafting regression marker; archived logs are under `audit/matrix`.

Package checks verified the embedded version and TM Game Studio author, Java 21 bytecode in all 196 application classes, seven bundled JDBC entrypoints, and absence of smoke classes, duplicate ZIP entries, invalid class names, and stale signature metadata. The build and retained JARs match. All 88 earlier versioned JARs retain their original hashes; 89 versioned JARs now exist.

Retained artifact: `RecipeWeaver-3.7.jar`, 29,304,692 bytes, SHA-256 `3BB76E0EC30CEF39D16AA29B272394978EED130054B7DF14C05DDA10F00B72C8`.

The [audit report](../audit/CODE-AUDIT-2026-10-11.txt) records source scope, build logs, scanner findings and limitations, dependency advisory results, and remaining live-verification boundaries. SpotBugs reported 223 warnings, which must not be presented as a clean scan or as 223 confirmed bugs. Real player GUI/crafting clicks, uninstalled optional item integrations, and the remaining external SQL checks still need live testing. The next full release remains subject to 75 new substantive changes after this intermediate build.
